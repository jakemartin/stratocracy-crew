Running against live Claude, the Systems Engineer authored Combat.cpp — but referenced a bare Unit instead of strat::Unit (a namespace-qualification error). The code did not compile. The gate returned a compile failure, 0/8 tests ran, and the merge was blocked. The Balance Analyst correctly refused to run self-play against a non-compiling build.

This is the whole thesis working: the real compiler caught real agent-generated broken code — not a scripted demo. The gap it exposed: a plain sequential crew has no repair loop, so the run ended blocked.

The agent-authored module (Run 2)

#include "Combat.h"
#include <cmath>
#include <algorithm>

namespace strat {

int resolveDamage(const Unit& attacker, const Unit& defender, int terrainDefPct) {
    double hpRatio = static_cast<double>(attacker.hp) / static_cast<double>(attacker.hpMax);
    double terrainMult = 1.0 - (static_cast<double>(terrainDefPct) / 100.0);
    double raw = static_cast<double>(attacker.atk) * hpRatio * terrainMult;
    int rounded = static_cast<int>(std::lround(raw));
    int dmg = rounded - defender.def;
    return std::max(1, dmg);
}

bool defenderCanCounter(const Unit& defender, int distance) {
    return distance >= defender.rangeMin && distance <= defender.rangeMax;  // both bounds
}

} // namespace strat
